How pairing works

  1. Open the mcp folder from the repository.
  2. Run npm install and then npm start.
  3. The server prints a local pairing token. Paste it above.
  4. Enable Agent Bridge and save.

The bridge binds to loopback only. The MCP process can request playback, seeking, clip start/finish, marker state, clip metadata and opening Studio.
