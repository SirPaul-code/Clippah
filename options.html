ONE-TIME AGENT SETUP

No npm knowledge required

Open the downloaded Clippah folder, open mcp, then double-click setup.cmd. It installs what is missing, creates the private pairing token and copies it to your clipboard. Your agent's MCP command is simply clippah-mcp.cmd — no npm commands required.
