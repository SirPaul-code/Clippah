# Changelog

## 0.1.0 — 2026-10-06

Initial functional MVP.

### Added

- Manifest V3 Chromium extension.
- Largest-visible-video detection.
- Player overlay.
- IN/OUT timestamps sourced from `video.currentTime`.
- Keyboard IN/OUT controls.
- Marker persistence.
- User-invoked tab capture.
- Offscreen capture document.
- Player-area crop.
- Local IndexedDB clip storage.
- Clippah Studio.
- 16:9, 9:16 and 1:1 output.
- Crop, blur-background and fit modes.
- Drag-to-reframe.
- Zoom.
- Manual keyframes.
- Smooth interpolation.
- Local WebM export.
- Installation, architecture and troubleshooting documentation.
- Packaging scripts.
- CI validation and ZIP artifact generation.
